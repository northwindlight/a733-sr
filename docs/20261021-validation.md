# 2026-10-21：MMD、字幕与原生 x2 验收

## 配置与改动

A733 / Debian 13 / Linux 6.6.98-5-aw2511，NPU 实读 PPU 1007.986 MHz，DDR 1800 MHz。
保留 VE 解码/编码和 GPU 色彩转换，默认切换 AnimeJaNai HD V3 UltraCompact 原生 x2。
模型输入 352×224、margin=16，960×540 为 3×3 块；输出 1920×1080。
默认关闭锐化、启用底部 20% 的源亮度保护；保护在 GPU 上完成，CPU 回退逐字节一致。

修正模型 RGB 与 ffmpeg GBR 通道顺序，使用 NEON 查表拼帧，并按实际平面尺寸分配 GPU 缓冲。
通用 x4 模型有 34 层卷积，单独使用 margin=36；不能沿用浅层模型的 margin=16。
GPU 输入的 NV12 色度偏移使用实际对齐高度，避免读取补齐行。
GPU 线程在输出写完后才计入完成帧，退出前释放 OpenCL 资源。
字幕内核按 NV12 / GBR 编译，避免触发 PowerVR 后台重编译线程的崩溃。

硬解 demo 在测试片末尾少交一帧：仅在容器有确定帧数、且尾部缺 1–2 帧时释放 VE 并软解补齐。
已知源帧数与处理帧数不一致会报错。封装时显式设置每包时长，修正最后一包沿用 1/25 秒的问题。

## 单帧阶段测量

同一 960×540 MMD 源帧、不锐化、不输出 NV12：

| 阶段 | 旧程序 + AnimeVideo x4 | 新程序 + AnimeJaNai x2 |
|---|---:|---:|
| NPU | 397.9 ms | 189.3 ms |
| 拼帧 | 125.3 ms | 27.2 ms |

单独保留旧模型、只改通道/NEON 时：NPU 约 398 ms 不变，拼帧约 134→88 ms。
以上为单帧样本，不是多轮统计；x2 省去四倍中间帧，对比包含模型与输出倍率的变化。

## 完整流水线

同一三秒 MMD 字幕片：960×540、15 fps、45 帧、AAC，目标 1920×1080。
板上无其它推理任务；旧版/新版依次运行于独立 systemd 服务。

| 项目 | 原线上版本 | 最终候选版本 |
|---|---:|---:|
| 总耗时 | 26.0 s | **13.7 s** |
| 服务 cgroup 内存峰值 | 286.0 MiB | **103.8 MiB** |
| 实际解码核验输出帧 | 44（发现旧缺陷） | **45/45** |
| 输出视频帧率 | 尾包时长不准 | **15/1** |
| 输出视频 / 音轨时长 | 视频短于源 | **3.000 / 3.000 s** |

候选强制 `SR_CHUNK_FRAMES=17`，覆盖跨段及尾帧补齐；线上默认仍为 300。
最终候选服务从重新启动到本次验收后累计 CPU 时间约 5.20 秒；旧对照服务为 12.83 秒。
这不是功耗测量，累计 CPU 时间也含服务采样等工作。耗时仅为短片单次结果，不能承诺所有分辨率都相同倍速。
